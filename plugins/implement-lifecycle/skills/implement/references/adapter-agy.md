# Antigravity (agy) Adapter

Spawn a fresh isolated child via `invoke_subagent` with `TypeName: "self"`, instructing the child to `read_file` the mapped canonical `SKILL.md` first, followed by the complete payload and `bundle=` path. Map `balanced` to `Model: "flash"` and `frontier` to `Model: "inherit"`. Save the returned `conversationId` in `state.json`. Use `swarm` (`action: "add"` with explicit `model`) only when the user explicitly pins a concrete model ID that `invoke_subagent` cannot express; otherwise prefer `invoke_subagent`. Keep scratch state (`state.json`, `bundle.md`, findings) under the conversation's scratch directory.

For continuations (addressing feedback, follow-up delta reviews, clarifications, and re-verification), read `conversationId` from `state.json` and use `send_message` (`Recipient: "<conversationId>"`) rather than spawning a new child. Pass findings directly to the existing `implement-code` author child in its Continuation Mode without loading a second skill.
